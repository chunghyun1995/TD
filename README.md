# STARLIGHT · 팬 러시

브라우저에서 플레이하는 한국어 타워 디펜스 게임입니다. 원래의 `타워디펜스.html`을 출발점으로 곡선 경로와 건설 지점 방식을 확장했습니다.

## 실행

`index.html`과 `assets/` 폴더 전체를 함께 배포합니다. 현재 사용 자료는 팬 이미지 `starlight-cast-v1.webp`, 멤버 `starlight-performers-v3.webp`, 수집 이미지 `starlight-summer-v2.webp` 및 `assets/dance/`의 멤버별 MP4·움직이는 WebP·포스터입니다. 계정이나 게임 서버는 필요하지 않습니다. 배포에서는 저장의 안정성을 위해 HTTP/HTTPS를 사용하세요. 아래 v4–v6 항목은 이전 버전의 변경 기록이며, 현재 캐릭터·공연장은 STARLIGHT 항목을 참고하세요.

GitHub Pages: 저장소 **Settings → Pages → Deploy from a branch → main / (root) → Save**. 배포 후 `https://chunghyun1995.github.io/TD/`에서 플레이할 수 있습니다. 실제 배포 완료 여부는 Pages 화면과 Actions에서 확인하세요.

이 로컬 패키지의 실행 파일은 `dist/index.html`입니다. GitHub 저장소에는 동일 파일을 루트 `index.html`로 업로드합니다.

## 콘텐츠

### 모바일 UI와 2.5D 그래픽 업데이트

### 화면 배율 수정 및 성능 최적화

고해상도 화면에서 캐시를 복사할 때 배율이 중복 적용되어 전장 일부가 확대되는 버그를 수정했습니다. 캐시 복사는 픽셀 좌표로 처리하고, 화면 표시 크기에 따라 내부 해상도를 조절합니다. 화면 폭 360/960/1280px와 기기 픽셀 배율 1/1.25/1.5/2/3의 15개 조합에서 첫 프레임과 캐시 프레임이 완전히 일치함을 픽셀 비교로 검증했습니다.

모바일 그리기는 최대 30fps, PC는 최대 60fps입니다. 게임 시간과 전투 계산은 그리기 주기와 분리합니다. 준비·일시정지·모달 상태에서는 화면 변경 시에만 그리며, 숨겨진 탭에서는 그리기를 중단합니다. HUD도 바뀐 값만 갱신합니다. 맵, 웨이브 요약, 타워 능력과 지원 효과를 재사용하고, 적 목표는 배열 정렬 없이 한 번의 탐색으로 선택합니다. 적 이동은 이전 경로 구간부터 이어 계산합니다. 연속 발사 효과음 생성도 제한했습니다.

24개 타워·80개 적을 사용한 CPU 벤치마크에서 목표 탐색 2만 회는 약 295ms에서 33ms로 줄었습니다. 이는 목표 탐색 계산에 대한 측정이며 실제 기기의 전체 게임 FPS 수치는 아닙니다. 180웨이브 재검증의 승패·보상·진행 결과는 이전 버전과 동일합니다.

모바일 전투 화면은 compact HUD, 건설/관리/공세 탭, 가로 스크롤 타워 목록, 전장 바로 아래의 웨이브 시작 버튼으로 구성했습니다. 타워를 누르면 관리 탭으로 전환됩니다. 320px 작은 화면부터 세로/가로 화면에 대응하며 터치 선택 범위를 화면 크기에 맞게 보정합니다.

Canvas의 표시 계층에 기울어진 2.5D 투영을 적용했습니다. 두께가 있는 지형, 도로의 높이, 입체 기단과 타워별 모델, 나무와 암석, 그림자, 광원, 적 캐릭터의 높이와 앞뒤 정렬을 표현합니다. 정적 지형은 캐시하고 고해상도 화면의 픽셀 배율은 최대 2배로 처리합니다. 게임 좌표와 저장 형식은 유지합니다.

모바일 건설·관리 전환과 준비 상태 복원을 브라우저에서 확인했습니다. 전투 180웨이브 회귀 검사, 투영/역투영 일치, 7종 타워·8종 적·4개 테마와 전투 효과 렌더링 검사도 통과했습니다.

- 12개 작전 · 6개 경로 · 숲/강/사막/설원 테마 · 작전별 적 특성
- 작전당 15웨이브, 총 180웨이브. 5·10·15웨이브 보스, 최종 작전 3보스
- 타워 7종: 연사포, 레일건, 박격포, 빙결탑, 전격탑, 산성탑, 지원탑
- 타워 5레벨과 14개 특화. 선두/강한 적/가까운 적/후미 목표 선택, 투자금 70% 회수
- 보병/척후병/중장갑/재생체/방패병/잠행자/군집/보스
- 궤도 폭격, 시간 봉쇄, 과부하 스킬. 재사용 시간과 연구 강화
- 별 평가와 4개 영구 연구. 작전 순서 해금, 최고 별 기록 유지
- 웨이브 준비 상태 자동 저장과 이어하기, JSON 저장 파일 내보내기/가져오기
- 일시정지, 탭 비활성 시 자동 정지, 1/2/3배속, 자동 진행, 합성 음향
- 반응형 화면, 터치와 키보드 조작

## 조작

타워를 선택하고 전장의 점선 원을 누르면 건설합니다. 타워를 누르면 강화, 특화, 목표, 회수를 설정할 수 있습니다. 웨이브 시작 전 적 구성을 확인하세요.

`1–7`: 타워 · `Space`: 웨이브 시작 · `P`: 일시정지 · `U`: 강화 · `Q/W/E`: 스킬 · `Esc`: 선택 취소. 폭격은 Q/버튼 선택 후 전장의 지점을 누릅니다.

장갑은 레일건·철갑탄·산성탑, 은신은 지원탑·박격포·전격탑, 재생은 산성탑으로 대응하세요. 지원 효과는 중첩되지 않습니다.

## 저장과 연구

브라우저 `localStorage`에 기록합니다. 전투 중 종료하면 직전 웨이브 준비 상태부터 다시 시작합니다. 웨이브 중 타워 변경과 사용 자금은 해당 웨이브 종료 전까지 준비 상태 저장에 반영되지 않습니다. 같은 브라우저·같은 웹 주소에서 이어갈 수 있습니다. 다른 기기로 이동하려면 설정에서 저장 파일을 내보낸 후 가져오세요.

기지 손실 0이면 별 3개, 손실 7 이하면 별 2개, 나머지 성공은 별 1개입니다. 재도전으로 별을 중복 획득할 수 없고 최고 기록이 갱신됩니다. 연구는 각 4단계, 비용 1/2/3/4점이며 다음 작전 또는 이어하기부터 적용됩니다. 연구 시작 자금 보너스는 신규 작전 시작 시 적용됩니다.

## 검증과 플레이 시간

실제 게임 로직을 이용한 자동 구매/배치/스킬 사용 시뮬레이션에서 12개 작전과 180개 웨이브를 모두 완료했습니다. 총 1배속 전투 시간은 약 **198분**이었습니다. 배치와 준비 시간을 더하면 **약 3–4시간**을 목표로 한 분량입니다. 2/3배속, 전략, 숙련도에 따라 실제 시간은 달라집니다. 사람의 2시간 전체 플레이 테스트를 수행한 수치는 아닙니다.

경로 화면 범위, 건설 지점 간격, 타워 강화와 특화, 준비 상태 저장 복원, 방어력/방어 무시, 중복 처치 보상 방지, 목표 우선순위, 정지와 스킬을 검증했습니다.

## 알려진 범위

싱글 플레이 게임입니다. 온라인 순위, 서버 저장, 멀티플레이와 클라우드 계정은 포함하지 않습니다. 저장은 사용자가 자신의 기록을 수정할 수 있는 로컬 형식입니다.

## v4 · 전장 중심 UI

전투 화면은 전체 뷰포트를 사용합니다. 자금·기지·웨이브, 일시정지·배속, 스킬·출격을 맵 위에 배치했습니다. 건설·강화·공세 정보는 필요할 때 여는 패널이며, 타워 선택 후 목록이 닫힙니다. 메뉴에서 작전 지도·연구소·교범·설정·음향을 이용할 수 있습니다.

모바일 세로 화면에서는 지면 카메라를 회전해 전체 경로를 세로로 표시하고 타워 모델은 똑바로 유지합니다. 화면 방향과 크기 변경에 맞춰 좌표·사거리·깊이 순서를 함께 갱신합니다. 주 조작 버튼은 44–54px 이상이며 휴대폰 안전 영역을 고려합니다. Canvas 지형 캐시와 모바일 30fps 렌더링 최적화는 유지했습니다.

32개 화면 크기/DPR 조합에서 캐시 프레임 픽셀 일치, 12개 맵의 플랫폼 범위·터치 좌표·역변환, 패널 토글과 메뉴 일시정지 복원을 검증했습니다. 180개 웨이브 캠페인 회귀 검증을 통과했으며 기존 저장 형식을 유지합니다. 브라우저 크기 조절로 모바일 화면을 검증했고 실물 모바일 기기에서는 아직 테스트하지 않았습니다.

## v5 · 전투 정교화

**목표 선택과 화력 배분.** 날아가는 탄환의 예상 피해만으로 처치될 적은 단일 공격 타워가 건너뛰어 다음 적을 노립니다. 목표가 먼저 쓰러지면 탄환은 근처의 적으로 방향을 틉니다. 빙결탑은 둔화되지 않은 적, 산성탑은 중독되지 않은 적을 먼저 노립니다. 박격포는 포탄 비행시간 동안의 이동을 예측해 착탄 지점에 쏘고, 지면에 착탄 예정 범위를 표시합니다. '강한 적'은 최대 체력이 아니라 남은 체력(보호막 포함) 기준이며, '마무리(남은 체력 최소)' 우선순위를 추가했습니다.

**피해 유형과 상성.** 보호막이 먼저 피해를 받고 남은 피해가 장갑을 거쳐 체력에 들어갑니다.

| 유형 | 타워 | 장갑 | 보호막 |
|---|---|---|---|
| 물리 | 연사포 | 막힘 | 100% |
| 관통 | 레일건, 연사포 철갑탄 | 무시 | 75% |
| 폭발 | 박격포 | 막힘 | 125% |
| 냉기 | 빙결탑 | 막힘 | 100% |
| 에너지 | 전격탑 | 절반 무시 | 160% |
| 산성·화염 | 산성탑 지속 피해, 네이팜 화상 | 무시 | 50% |

**적 고유 행동.** 척후병은 피격 시 한 번 질주(+45%), 중장갑은 손상될수록 장갑이 약해지고, 방패병은 3.5초간 피격이 없으면 보호막을 재충전합니다. 잠행자는 피격되면 1.2초 노출되어 범위 공격 후 단일 타워가 추격할 수 있습니다. 재생체는 화상으로도 재생이 막힙니다. 보스는 9초마다 진군 함성으로 주변 적을 3초간 가속하고, 10·15웨이브 보스는 체력 50%에서 최대 체력 12%의 긴급 방어막을 펼칩니다.

**웨이브 편성.** 적 종류와 수, 웨이브 총 길이는 그대로 두고 4–7기 분대로 나눠 출현시킵니다. 분대 안에서는 장갑·방패병이 앞, 척후병이 뒤에 서고 군집은 더 촘촘하게 붙습니다. 공세 정보에서 분대 수와 출현 적의 특성을 확인할 수 있습니다.

**밸런스.** 전격탑 과충전은 설명과 달리 연쇄 3명 모두에 ×2.2가 걸려 연쇄 번개보다 항상 우월했으므로, 연쇄 없는 단일 ×2.6으로 바꿨습니다. 레일건 결정타는 중장갑 ×1.4와 보스 우선 조준을 추가했고, 지원탑 관측망은 피해 +35%에서 +40%로 올렸습니다.

**피드백.** 피해 숫자를 적별로 묶어 표시합니다(노란색 약점, 회색 저항, 전장 메뉴에서 끄기 가능). 질주·함성·긴급 방어막은 전장에 문구로 표시합니다. 타워 패널에 초당 피해, 피해 유형과 상성, 이번 작전의 누적 피해·처치 수를 보여 줍니다. 상점 버튼에 피해 유형을, 교범에 상성표와 적 특성을 추가했습니다.

**검증.** 같은 자동 구매·배치·스킬 봇으로 원본과 v5의 180웨이브 캠페인을 비교했습니다. 원본 12/12 승리, 기지 손실 합계 49, 1배속 전투 198.5분. v5 12/12 승리, 기지 손실 46, 199분. 봇은 새 상성을 활용하지 않으므로 실제 플레이에서는 상성 대응으로 더 유리해집니다. 발사 후 명중하지 못한 탄환은 4.7%에서 1.8%로, 박격포 유효 착탄률은 91.7%에서 94.0%로 개선되었습니다. 데스크톱 1366×800과 모바일 390×844 브라우저에서 콘솔 오류 없이 전투·관리 패널·교범 표시를 확인했습니다. 사람의 전체 플레이 테스트는 아직 수행하지 않았습니다. 저장 형식은 기존과 호환됩니다.

## v6 · 장난감 정원 그래픽

**빈 공간 없는 전장.** 전장 판을 어두운 허공에 띄우지 않고, 화면이 보여 주는 범위 전체에 테마 지형을 이어 그립니다. 숲은 울창한 숲과 버섯, 강은 호수와 연잎·갈대, 사막은 모래 언덕과 선인장, 설원은 눈밭과 눈사람입니다. 전장은 둥근 모서리의 섬처럼 살짝 솟아 있고, 적이 오는 길은 화면 가장자리에서 경사로(강은 나무다리)를 타고 올라옵니다. 휴대폰 세로·가로 화면에서도 HUD 뒤까지 지형이 채워집니다.
